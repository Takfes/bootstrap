# Animation & Transition Guide

Load this file when applying polish in Phase 5. The core principle: **the best animation is the one you don't notice.**

---

## The Golden Rules

1. **Consistency over variety** — 1–2 transition types for the entire deck
2. **Subtlety over flash** — professional animations are barely noticeable
3. **Purpose over decoration** — every animation must aid comprehension, not decorate
4. **The boardroom test** — if it would distract a CEO, don't use it

---

## Transition Tier System

### Tier 1 — Always Professional (use freely)

| Transition | Duration | Brand fit | Use for |
|---|---|---|---|
| **Fade** | 0.6s | All | Default — 95% of slides |
| **Push** | 0.4s | Tech Keynote, Startup | Sequential content, timelines |
| **Morph** | 0.8s | Corporate, Financial | Repeated elements across slides |

### Tier 2 — Special Occasions Only

| Transition | Duration | Limit | Use for |
|---|---|---|---|
| **Zoom** | 0.5s | 2–3× per deck | Product reveals, before/after |
| **Reveal** | 0.6s | Once per section | Major section transitions |
| **Wipe** | 0.5s | 3–5× per deck | Image-heavy slides |

### Tier 3 — Never Use

Ferris Wheel, Curtains, Origami, Page Curl, Dissolve, Flash, Honeycomb.

These draw attention to the transition itself, feel amateurish, and fail the boardroom test.

---

## Entrance Animations

| Element | Effect | Duration | Notes |
|---|---|---|---|
| Title | Fade In | 0.4s | With Previous |
| Body text | Fade In | 0.4s | With Previous — all text together |
| Bullet list | Fade In (staggered) | 0.3s each | After Previous, 0.3s between items |
| Hero image | Fade In | 0.6s | With Previous |
| Product image | Wipe From Bottom | 0.6s | Rising reveal feels premium |
| Chart | Grow & Turn | 0.8s | On Click — let audience process |

---

## Emphasis Animations (The "AHA!" Moment)

Use emphasis on **one slide only** — the single most important slide in the deck:

| Element | Effect | Duration | Repeat |
|---|---|---|---|
| Key metric / number | Pulse | 0.8s | Once |
| CTA / call-to-action | Grow (scale 1.1×) | 0.6s | Once |
| Critical highlighted text | Color Pulse | 0.5s | Once |

## Per-Brand Animation Strategy

### Tech Keynote
- Transitions: Push, Fade
- Max animations per slide: 2
- Duration preference: 0.6s
- Entrance: Fade In only
- Emphasis: None — let the content speak
- Philosophy: Pure minimalism

### Corporate Professional
- Transitions: Morph, Fade
- Max animations per slide: 3
- Duration preference: 0.8s
- Entrance: Fade In, occasionally Wipe
- Emphasis: Subtle Pulse on key data
- Philosophy: Smooth, never distracting

### Creative Bold
- Transitions: Zoom, Reveal, Push
- Max animations per slide: 4
- Duration preference: 0.5s
- Entrance: Mix of Fade, Zoom, Wipe
- Emphasis: Grow, Color Pulse
- Philosophy: Playful but purposeful

### Financial Elite
- Transitions: Fade only
- Max animations per slide: 1
- Duration preference: 0.4s
- Entrance: Fade In only
- Emphasis: None
- Philosophy: Maximum restraint

### Startup Pitch
- Transitions: Push, Fade
- Max animations per slide: 2
- Duration preference: 0.3s
- Entrance: Fade In, quick
- Emphasis: Pulse on key metrics
- Philosophy: Fast pace matches startup energy

## Duration Reference

| Speed | Range | Use |
|---|---|---|
| Super fast | 0.2–0.3s | Startup energy |
| Fast | 0.4–0.5s | Modern, crisp |
| Medium | 0.6–0.7s | Standard professional |
| Slow | 0.8–1.0s | Sophisticated, data-heavy |
| Too slow | >1.0s | Avoid — feels sluggish |

---

## Quick Reference by Slide Type

| Slide type | Transition | Entrance | Emphasis | Duration |
|---|---|---|---|---|
| Title / cover | Fade | Fade In | None | 0.6s |
| Section break | Reveal | Fade In | None | 0.6s |
| Bullets | Fade | Fade In (stagger) | None | 0.3s each |
| Full image | Fade / Wipe | Wipe From Bottom | None | 0.6s |
| Quote | Fade | Fade In | None | 0.4s |
| Data / chart | Fade | Grow & Turn | Pulse (key number) | 0.8s |
| Comparison | Push | Fade In (sequence) | None | 0.5s |
| Product / hero | Zoom | Wipe From Bottom | Optional Pulse | 0.6s |
| Thank you / closing | Fade | Fade In | None | 0.4s |

---

## Animation Checklist

- [ ] 1–2 transition types only
- [ ] All similar elements animate the same way
- [ ] Duration consistent across similar animations
- [ ] Brand style guidelines followed
- [ ] Every animation aids comprehension (none purely decorative)
- [ ] Emphasis animation on one slide only
- [ ] All animations < 1.0s
- [ ] No Tier 3 transitions
- [ ] Passes the boardroom test

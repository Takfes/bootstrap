# Description Templates for Image Generation

This document provides complete image description examples organized by category. Each example demonstrates all 6 critical dimensions:

1. **Art Style** - Visual medium and rendering approach
2. **Scene Elements** - Subjects, objects, and composition
3. **Setting/Environment** - Location, time, weather, context
4. **Mood/Atmosphere** - Emotional tone and energy
5. **Technical Details** - Camera angle, lighting, lens, framing
6. **Context/Narrative** - Story, purpose, meaning

## Template Formula

Always include dimensions in this order:

```
[Art Style] image/painting/scene of [Elements] in/at [Setting], [Mood] atmosphere, [Technical Details], [Context/Narrative]
```

## Quick Reference: Dimension Checklist

Use this checklist when building descriptions:

- [ ] **Art Style** - What visual medium? (photo, 3D, painting, digital art, etc.)
- [ ] **Elements** - What's in the frame? (subjects, objects, foreground/background)
- [ ] **Setting** - Where and when? (location, time, weather, environment)
- [ ] **Mood** - What feeling? (emotional tone, atmosphere, energy)
- [ ] **Technical** - How is it captured? (angle, lighting, lens, composition)
- [ ] **Context** - What's the story? (narrative, purpose, meaning)
